## Ghi chú

Bài lab này được thực hiện độc lập (không nhóm). Một thành viên duy nhất chịu trách nhiệm toàn bộ các phần việc:

- Cải tiến `system_prompt.md` qua các vòng v0 → v3
- Cập nhật `tools.yaml` với description và schema rõ ràng
- Thiết kế 10 team eval cases (5 single-turn + 5 multi-turn)
- Chạy eval suite và phân tích failure traces
- Xây dựng UI chat (`app.py`) hiển thị tool calls và artifact version
- Hoàn thành `REPORT.md` với evidence từ run thật
